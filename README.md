# «ВИТРУВИЙ» для Foundry VTT

Система по правилам «ВИТРУВИЙ» Beta 3.1 (автор системы Георгий Воронин, [vitruvium.ru/rules](https://vitruvium.ru/rules)) и модуль объёмных кубиков для Dice So Nice. Foundry VTT 14 (проверено на 14.370). Интерфейс на русском и английском.

В системе только то, что есть в правилах: характеристики, домены и способности, атрибуты, имущество, вдохновение, статусы, уровни и аспекты, проверка характеристики особыми шестигранными кубиками. Боя, здоровья, инициативы и расстояний правила не задают, поэтому их здесь нет.

## Что внутри

| Папка | Пакет | Что делает |
|---|---|---|
| `system/` | система `vitruvium` | актеры, предметы, лист, проверки, правила в компендиуме |
| `modules/vitruvium-dice/` | модуль `vitruvium-dice` | кубик `dv` для Dice So Nice |
| `modules/vitruvium-map/` | модуль `vitruvium-map` | общая карта мира и заявки игроков |
| `tools/` | | сборка компендиума, граней кубика, архивов |
| `tests/` | | проверка правил броска в Node без Foundry |

## Установка

В Foundry: «Системы» → «Установить систему» → в поле «URL манифеста» вставить
`https://github.com/x4isfate/vitruvium/releases/latest/download/system.json`.
Модуль кубиков ставится так же, по ссылке `https://github.com/x4isfate/vitruvium/releases/latest/download/module.json`.
Модуль карты: `https://github.com/x4isfate/vitruvium/releases/latest/download/vitruvium-map.json`.

Новые версии подтягиваются кнопкой «Обновить» в списке систем и модулей.

## Как играть

Окно приветствия открывается при первом запуске и из «Настроек игры». Коротко:

- Проверка: нажать на название характеристики в листе. В окне выбираются домен, сложность, преимущества, помехи, вдохновение.
- Мастер отправляет запрос проверки кнопкой с рупором на панели токенов. Провал можно отметить как частичный успех прямо на карточке.
- В чате `/r 3dv` бросает три особых кубика. Другие кубы система отклоняет.

## Карта мира

Модуль для политической игры, где игроки играют богами и вместе с мастером меняют мир. На сцене появляется группа «Карта мира» в панели слева.

- Объекты: города, крепости, святилища. Значок, цвет и размер берутся из типа.
- Линии: реки сужаются к истоку и петляют, дороги рисуются пунктиром с обводкой.
- Области: закрашиваются по клеткам сетки, с Alt рисуется свободный контур. Область лежит на слое. Режим «Поверх» оставляет под ней чужую землю: так видна спорная территория.
- У любого элемента есть название, описание, демиург, статусы с уровнями вроде 7/10, аспекты со своими статусами и связи с другими элементами. У области лист показывает, какие объекты стоят на её земле.

Мастер правит карту сразу. Правки игрока сначала попадают в его черновик, другие игроки их не видят. Игрок отправляет черновик заявкой с названием и пояснением. Мастер в окне «Заявки» смотрит правки на карте, принимает или отклоняет сразу несколько заявок, а по спорной назначает проверку сложностью 1–6. Игрок бросает её по карточке в чате обычной проверкой Витрувия. При успехе заявка принимается сама, это отключается в настройках. Если карта успела измениться после подачи заявки, очередь это покажет, и мастер решит, применять правку поверх или пропустить.

Данные лежат в журнале «Атлас: <сцена>», по странице на элемент. Типы и слои мастер настраивает кнопкой «Типы и слои». API модуля: `game.modules.get("vitruvium-map").api`.

## Разработка

```sh
npm install
npm run lint        # синтаксис JS, JSON и шаблонов
npm test            # правила броска, геометрия и заявки карты
npm run rules       # пересобрать журнал правил из _Ultra/src/page.html
npm run packs       # собрать компендиум LevelDB
npm run dice-art    # перерисовать грани кубика (нужен Playwright)
npm run dist        # архивы в dist/
```

Релиз: поднять `version` в `system/system.json`, `modules/vitruvium-dice/module.json` и `modules/vitruvium-map/module.json`, дописать `CHANGELOG.md` и опубликовать релиз с тегом `vX.Y.Z` (на GitHub через «Draft a new release» или пушем тега). GitHub Actions соберёт архивы и приложит их к релизу. Можно запустить и вручную: Actions → Release → Run workflow.

Для разработки удобно сделать ссылки из папки данных Foundry на `system/` и `modules/vitruvium-dice/`.

## Расширение и Ultra

Ядро рассчитано на модули и производные системы. Ветка `ultra` отведена под систему Ultra поверх этого ядра.

- `CONFIG.VITRUVIUM`: характеристики, пределы, уровни создания, грани кубика, иконки. Меняется в хуке `init` модуля.
- `game.vitruvium`: `check(actor)`, `rollCheck(actor, options)`, `prepareCheck`, `requestCheck()`, `welcome()`, класс кубика и окна.
- Хуки: `vitruvium.init`, `vitruvium.ready`, `vitruvium.preRollCheck` (вернуть `false`, чтобы отменить), `vitruvium.rollCheck`.
- Цвета и шрифт заданы переменными `--v-*` в `system/styles/vitruvium.css`, модуль может переопределить их на `.vitruvium`.
