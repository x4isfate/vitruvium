# «ВИТРУВИЙ» для Foundry VTT

Система по правилам «ВИТРУВИЙ» Beta 3.1 (автор системы Георгий Воронин, [vitruvium.ru/rules](https://vitruvium.ru/rules)) и модуль объёмных кубиков для Dice So Nice. Foundry VTT 13–14.

В системе только то, что есть в правилах: характеристики, домены и способности, атрибуты, имущество, вдохновение, статусы, уровни и аспекты, проверка характеристики особыми шестигранными кубиками. Боя, здоровья, инициативы и расстояний правила не задают, поэтому их здесь нет.

## Что внутри

| Папка | Пакет | Что делает |
|---|---|---|
| `system/` | система `vitruvium` | актеры, предметы, лист, проверки, правила в компендиуме |
| `modules/vitruvium-dice/` | модуль `vitruvium-dice` | кубик `dv` для Dice So Nice |
| `tools/` | | сборка компендиума, граней кубика, архивов |
| `tests/` | | проверка правил броска в Node без Foundry |

## Установка

Репозиторий приватный, поэтому Foundry не скачает систему по ссылке на манифест. Ставить из архивов релиза:

1. Скачайте `vitruvium.zip` и `vitruvium-dice.zip` со страницы Releases.
2. Распакуйте первый в `Data/systems/vitruvium`, второй в `Data/modules/vitruvium-dice`.
3. Перезапустите Foundry и создайте мир на системе «Витрувий».
4. Для объёмных кубиков включите в мире Dice So Nice и «Витрувий: кубики».

Если репозиторий станет публичным, достаточно ссылок на манифест:
`https://github.com/x4isfate/vitruvium/releases/latest/download/system.json` и `…/module.json`.

## Как играть

Окно приветствия открывается при первом запуске и из «Настроек игры». Коротко:

- Проверка: нажать на название характеристики в листе. В окне выбираются домен, сложность, преимущества, помехи, вдохновение.
- Мастер отправляет запрос проверки кнопкой с рупором на панели токенов. Провал можно отметить как частичный успех прямо на карточке.
- В чате `/r 3dv` бросает три особых кубика. Другие кубы система отклоняет.

## Разработка

```sh
npm install
npm run lint        # синтаксис JS, JSON и шаблонов
npm test            # правила броска
npm run rules       # пересобрать журнал правил из _Ultra/src/page.html
npm run packs       # собрать компендиум LevelDB
npm run dice-art    # перерисовать грани кубика (нужен Playwright)
npm run dist        # архивы в dist/
```

Релиз: поднять `version` в `system/system.json` и `modules/vitruvium-dice/module.json`, дописать `CHANGELOG.md` и опубликовать релиз с тегом `vX.Y.Z` (на GitHub через «Draft a new release» или пушем тега). GitHub Actions соберёт архивы и приложит их к релизу. Можно запустить и вручную: Actions → Release → Run workflow.

Для разработки удобно сделать ссылки из папки данных Foundry на `system/` и `modules/vitruvium-dice/`.

## Расширение и Ultra

Ядро рассчитано на модули и производные системы. Ветка `ultra` отведена под систему Ultra поверх этого ядра.

- `CONFIG.VITRUVIUM`: характеристики, пределы, уровни создания, грани кубика, иконки. Меняется в хуке `init` модуля.
- `game.vitruvium`: `check(actor)`, `rollCheck(actor, options)`, `prepareCheck`, `requestCheck()`, `welcome()`, класс кубика и окна.
- Хуки: `vitruvium.init`, `vitruvium.ready`, `vitruvium.preRollCheck` (вернуть `false`, чтобы отменить), `vitruvium.rollCheck`.
- Цвета и шрифт заданы переменными `--v-*` в `system/styles/vitruvium.css`, модуль может переопределить их на `.vitruvium`.
